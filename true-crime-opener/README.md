# Das rote Netz

Fiktiver True-Crime-Cold-Open. Keine echten Personen, keine echten Fälle. Deutscher On-Screen-Text, 1080×1920, 25 Sekunden.

Composition: `ColdOpen`

```console
npm install
npm run hits
npx remotion render ColdOpen out/cold-open.mp4
```

Der Schnitt liegt unter `out/cold-open.mp4`. Die Hits sind synthetisch (`scripts/make-hits.mjs`) und liegen als `public/hits.wav` bei.
